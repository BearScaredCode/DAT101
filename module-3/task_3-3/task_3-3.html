1. What is the difference between invoking and creating a function?

    2. Creating a function means defining it (writing what it should do). Invoking a function means calling it so the code actually runs.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Code blocks use curly braces { } to group statements. Semicolons ; end statements; in JavaScript they are often optional, but it is safer and clearer to use them.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. Then the stored value becomes undefined, because the function did not return anything.

  4. How do we separate parameters from each other when creating a function?

    5. We separate parameters with commas, for example: function sum(a, b, c).

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. When creating, parameter names are placeholders. During invocation, argument values are passed by position to those placeholders, so the order matters more than the names in the call.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. If an argument is not provided, JavaScript gives that parameter the default value undefined (unless we set our own default value in the function).

  7. Explain what happens when we use recursive functions.

    8. A recursive function calls itself repeatedly. It must have a base case to stop; otherwise it keeps calling itself until stack overflow (maximum call stack exceeded).
