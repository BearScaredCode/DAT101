1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. I use constants for values that stay the same, and variables for values that need to change while the program runs. So no, everything cannot be constants.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses decide what gets calculated first. That can change the final answer a lot.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can use toFixed(n), like toFixed(2) for two decimals. Another way is rounding with Math.round.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Usually we should not compare floats with ===. We compare the difference, for example Math.abs(a - b) < 0.000001.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. They return boolean values: true or false. We usually check this with an if statement.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() gives a random decimal number from 0 up to (but not including) 1. We use it for random numbers in games, tests, and choosing random items.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus (%) gives the remainder after division. It is useful for checking even/odd numbers and repeating patterns.
