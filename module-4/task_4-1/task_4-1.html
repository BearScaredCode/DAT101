1. Why is object-oriented development so important in programming?

    2. Object-oriented development helps us organize code into reusable parts (classes/objects). It makes bigger programs easier to understand, maintain, and expand over time.

  2. In Task 1, we create a static object called "AccountType." Explain what this object is used for and how this type of object can help us in software development.

    3. AccountType stores fixed account categories in one place (for example Normal, Saving, Pension). This avoids magic strings, reduces typing mistakes, and makes code more consistent.

  3. Discuss why we use encapsulation in classes. Why do we want to "hide" code within our class? Explain how we can create "private" and "public" members in a constructor function.

    4. Encapsulation protects internal data so objects cannot be changed in unsafe ways. In modern JS classes, private members use #name, while public members are normal methods/properties. In constructor-function style, we can use closure variables for private data and attach public members with this.method = ....

  4. Explain what happens when we use the "new" command in JavaScript.

    5. new creates a new object instance, links it to the constructor/class prototype, runs the constructor, and returns the new object.
